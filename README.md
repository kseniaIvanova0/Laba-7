# Лабораторная работа 7: Структуры и файлы

## Автор
Иванова Ксения, группа ПИ-261, Вариант 6

## Цель
Научиться описывать запись объекта структурой `struct`, хранить коллекцию записей,
читать и проверять данные текстового файла, выполнять запрос и сохранять
одинаковый отчёт на экране и в файле.

## Описание
Программа читает записную книжку из файла `input.txt`. Каждая строка —
один знакомый: фамилия, имя, дата рождения, адрес, телефон. Программа
запрашивает улицу, выводит всех знакомых с этой улицы, а также находит
самого молодого и самого старого знакомого среди всех записей.

## Исходные данные
Файл `input.txt` в папке проекта, не более 100 строк, поля через `;`:
`Фамилия;Имя;ГГГГ-ММ-ДД;Адрес;Телефон`

## Ожидаемые результаты
Файл `output.txt` и экран получают одинаковый отчёт:
список совпадений по улице (или `EMPTY`), количество, самый молодой и самый старый.
